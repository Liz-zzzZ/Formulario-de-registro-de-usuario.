 Sistema de Autenticación y Registro de Usuarios

### 📝 Descripción
Este proyecto es una aplicación web enfocada en la gestión de accesos y formularios dinámicos. Implementa un sistema de autenticación donde un usuario debe iniciar sesión exitosamente para desbloquear el módulo de administración, permitiendo el registro controlado de nuevos perfiles en el sistema.

### 🛠️ Tecnologías de Desarrollo
* **Framework**: React.js
* **Lenguaje**: TypeScript
* **Herramienta de Construcción**: Vite
* **Estilos**: CSS3

### 🚀 Funcionalidades Clave
* **Módulo de Login**: Validación de credenciales de usuarios.
* **Control de Rutas/Vistas**: Restricción de acceso hasta un inicio de sesión válido.
* **Módulo de Registro**: Formulario estructurado para dar de alta nuevas cuentas.

### 🎓 Aprendizaje Obtenido
* Manejo de estados y hooks en React.
* Tipado estricto y seguridad en el código utilizando TypeScript.
* Control de versiones con Git y despliegue rápido con Vite.
